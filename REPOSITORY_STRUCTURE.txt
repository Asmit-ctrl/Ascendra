ASCENDRA REPOSITORY STRUCTURE
=============================

All code is now consolidated under the main Ascendra repository.

MAIN APPLICATIONS:
------------------

1. studio/
   - Main Next.js application
   - Student and teacher dashboards
   - Uses AI agents backend for all AI features
   - Environment: NEXT_PUBLIC_AI_AGENTS_URL

2. scheme-scribe/
   - Vite/React application for scheme generation
   - Standalone scheme and lesson plan generator
   - Now uses centralized AI agents backend
   - Environment: VITE_AI_AGENTS_URL

3. ai-agents/
   - Python FastAPI backend
   - Centralized AI generation service
   - Handles all scheme, lesson plan, and chat generation
   - Port: 8001

SUPPORTING DIRECTORIES:
-----------------------

4. arduino/
   - Arduino code for hardware integration
   - Mwalimu AI system

5. scripts/
   - Utility scripts for development and deployment
   - Setup, testing, and maintenance scripts

6. supabase/
   - Supabase configuration
   - Database migrations
   - RLS policies

IGNORED DIRECTORIES:
--------------------

_inventory/
   - Reference code and prototypes
   - Not part of main codebase
   - Added to .gitignore

CONFIGURATION FILES:
--------------------

- .gitignore - Excludes _inventory/ and build artifacts
- netlify.toml - Netlify deployment config
- BACKEND_CONSOLIDATION.txt - Backend consolidation guide
- REPOSITORY_STRUCTURE.txt - This file

DEPLOYMENT:
-----------

All applications share the same AI agents backend:
- Development: http://localhost:8001
- Production: Set via environment variables

Benefits:
- Single repository for version control
- Consistent dependencies
- Easier deployment
- Better code organization
- Shared improvements across all apps
