BACKEND CONSOLIDATION GUIDE
===========================

PROBLEM:
--------
The project had multiple systems for generating schemes and lesson plans:
1. Main Studio (Ascendra/studio) - Uses AI Agents Python backend
2. Scheme-Scribe App (Ascendra/scheme-scribe) - Was using Supabase Edge Functions
3. Different APIs, different error handling, maintenance nightmare

SOLUTION:
---------
Consolidate everything to use the centralized AI Agents Python backend at:
  Ascendra/ai-agents/

CHANGES MADE:
-------------

1. Teacher Profile Settings
   - Added layout file: studio/src/app/teacher/layout.tsx
   - Teachers now have same profile settings as students
   - Uses AppHeader component with profile dropdown

2. Fixed Lesson Generation Error
   - Updated: ai-agents/src/syncsenta_agents/api/lesson_architect_api.py
   - Normalizes scheme_id parameter (handles "None", "", "null", "undefined")
   - Prevents "Scheme not found: None" error

3. Centralized API Client
   - Created: scheme-scribe/src/lib/api-client.ts
   - Provides unified interface to AI agents backend
   - Replaces Supabase Edge Functions calls

4. Updated Lesson Plan Generation
   - Modified: scheme-scribe/src/components/LessonPlanDialog.tsx
   - Now uses apiClient.generateLessonPlan() instead of Supabase Edge Function
   - Consistent with main studio implementation

5. Repository Cleanup
   - Moved scheme-scribe-ai-reference to scheme-scribe
   - Removed separate .git repository
   - Added _inventory/ to .gitignore
   - All code now under main Ascendra repository

DEPLOYMENT REQUIREMENTS:
------------------------

1. AI Agents Backend MUST be running and accessible
   - Development: http://localhost:8001
   - Production: Set NEXT_PUBLIC_AI_AGENTS_URL environment variable

2. Environment Variables:
   
   Main Studio (Ascendra/studio):
   - NEXT_PUBLIC_AI_AGENTS_URL=<backend_url>
   
   Scheme-Scribe (Ascendra/scheme-scribe):
   - VITE_AI_AGENTS_URL=<backend_url>
   - VITE_SUPABASE_URL=<supabase_url>
   - VITE_SUPABASE_ANON_KEY=<supabase_key>

3. Restart AI Agents Backend after code changes:
   cd Ascendra/ai-agents
   # Kill existing process
   # Restart with: python -m syncsenta_agents.main

- Shared improvements benefit all apps
- No duplicate code
