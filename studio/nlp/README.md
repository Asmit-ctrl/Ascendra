# NLP & Vision Integration

This folder holds code and documentation for NLP helpers, vision ingestion, and integrations with external devices (e.g., ESP32-S3-CAM).

Goals:
- Provide image ingestion helpers and preprocessing pipelines
- Host lightweight NLP utilities (tokenization, text normalization)
- Define interfaces and examples for sending camera frames to the backend

Keep code minimal here; production implementations should live under `studio/src` and import from this folder as needed.
